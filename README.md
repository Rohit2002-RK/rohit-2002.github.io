# Rohit R Khed — Portfolio

Personal portfolio website for an Electronics & Communication Engineering graduate focused on embedded systems, IoT, electronics and software.

## Free deployment

1. Create a GitHub account at https://github.com/
2. Create a new public repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, `resume.pdf`, and the `assets` folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Your website will be available at `https://yourusername.github.io/`.

## Before publishing

- Replace `resume.pdf` with your real resume.
- Replace the GitHub placeholder URL with your GitHub profile.
- Replace `your.email@example.com` with your real email.
- Replace each "Add GitHub project" link with the corresponding repository.
- Add real project photos to `assets/` if available.
- Review all project descriptions so they exactly match your actual work.
